# Birthday Wonderland 🎀

A reusable, mobile-friendly birthday greeting website with a pastel pink-and-mint theme, floating decorations, four interactive gifts, and confetti.

## Files

- `index.html` — page structure and gift buttons
- `style.css` — colours, responsive layout, and animations
- `script.js` — editable greeting text, name personalisation, gifts, and confetti

## Personalise the messages

Open `script.js` and edit the text inside the `gifts` object. Each gift has a `title`, `icon`, and `text` function. The entered name is automatically included in the messages.

To change the gift cards' labels, edit the corresponding buttons in `index.html`.

## Publish with GitHub Pages

1. Create a new public repository named `birthday-wonderland` at https://github.com/new.
2. Upload all three website files (`index.html`, `style.css`, `script.js`) to the repository root. You may also upload this README.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait a few minutes. Your site should appear at `https://YOUR-USERNAME.github.io/birthday-wonderland/`.

## Phone-friendly upload

On your phone, open GitHub in Chrome and sign in. Create the new repository, then use **Add file → Create new file** to add each file one at a time. Name them exactly `index.html`, `style.css`, and `script.js`, paste the matching contents, and commit each file. If the editor is cramped, use Chrome's menu and enable **Desktop site**.

## Notes

- Google Fonts is used for decorative typography; if offline, the page falls back to system fonts.
- The site does not collect or send the entered name anywhere; personalisation happens in the browser.
- No existing repository is modified by this project.
